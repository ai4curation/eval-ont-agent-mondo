# PR: Add KY-related neuromyopathy term and establish it as parent for KY-related disease terms

## Summary

This PR creates a new MONDO term for "KY-related neuromyopathy" (MONDO:7770012) as requested in issue #9937 by the ClinGen Muscular Dystrophy and Myopathy GCEP. The new term serves as a parent class for three existing KY-related disease terms.

## Changes Made

### New Term Created
- **ID**: MONDO:7770012
- **Name**: KY-related neuromyopathy
- **Parent**: MONDO:0100546 (hereditary neuromuscular disease)
- **Definition**: "Any neuromyopathy in which the cause of the disease is a mutation in the KY gene."
- **Definition sources**: PMID:27484770, PMID:27485408, PMID:28488683, PMID:32818658
- **Creator**: https://orcid.org/0000-0002-2078-7280 (via ClinGen GCEP)

### Structural Changes

- Logical definition using intersection_of with has_material_basis_in_germline_mutation_in relationship

- Cross-reference to the GitHub issue for tracking
