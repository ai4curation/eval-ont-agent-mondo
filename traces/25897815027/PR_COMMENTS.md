# PR Summary: VeNom Cross-Reference Integration (Issue #5726)

## Overview
This pull request implements **Template 1** of the three-phase VeNom integration plan for issue #5726: adding VeNom cross-references to existing MONDO non-human animal (NHA) disease terms.

## Changes Made

### 1. Ontology Updates
- **File**: `src/ontology/mondo-edit.obo`
- **VeNom XRefs Added**: 229 exact matches from VeNom diagnosis codes to existing MONDO NHA terms
- **Source Format**: `xref: VeNom:{ID} {source="MONDO:equivalentTo"}`
- **Example**: 
  ```
  [Term]
  id: MONDO:0005630
  name: actinobacillosis
  ...
  xref: VeNom:21946 {source="MONDO:equivalentTo"}
  subset: venom_equine {source="VeNom:21946"}
  subset: venom_farm_animal {source="VeNom:21946"}
  ...
  ```

### 2. Subset Definitions
Added 6 new VeNom animal-type subset definitions to the mondo-edit.obo header:
- `venom_avian` - VeNom avian animal type subset
- `venom_equine` - VeNom equine animal type subset
- `venom_exotics` - VeNom exotics animal type subset
- `venom_farm_animal` - VeNom farm animal type subset
- `venom_large_animal` - VeNom large animal type subset
- `venom_small_animal` - VeNom small animal type subset

### 3. Subset Annotations
Each term with a VeNom xref includes `in_subset` annotations for relevant animal types. The source for each subset annotation is the VeNom ID, enabling future filtering and analysis by animal type (e.g., disease distribution across species).
